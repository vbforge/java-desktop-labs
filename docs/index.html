Requirements
// Java 21 or newer. That's it for prebuilt jars.

Build from source
# needs JDK 21 + Maven
git clone https://github.com/vbforge/java-desktop-labs.git
cd java-desktop-labs/apps/pathlab
mvn clean javafx:run
